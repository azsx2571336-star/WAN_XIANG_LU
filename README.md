# 《萬象錄》

《萬象錄》世界法典官方母稿 Repository。

> **《萬象錄》永不忘任何存在。**

## 專案定位

本 Repository 作為《萬象錄》世界觀的唯一 Canon 來源（Single Source of Truth）。

所有正式出版物，包括世界法典、世界百科、歷史紀錄、觀測手冊、DOCX、PDF 與未來遊戲資料，皆應以此處的 Markdown 母稿為基礎。

## 目前狀態

- Version：1.0
- Status：Foundation Complete
- Scope：第一部《世界法典》
